Risk-adjusted return — Sharpe ratio

The Sharpe ratio measures how much extra return a portfolio earns for each unit of risk (volatility) it takes on, above what you'd get holding something essentially risk-free. It's calculated as (portfolio return − risk-free rate) ÷ portfolio volatility. A higher number means you're being compensated better for the risk you're carrying: as a rough rule of thumb, below 1 is considered weak, 1–2 is decent, and above 2 is very good — though what counts as "good" varies a lot by asset class and time period.

Expected return is estimated via the Capital Asset Pricing Model (CAPM) — the direct academic extension of Markowitz's own framework: E(Ri) = Rf + βi × ERP, where βi is each ticker's real trailing beta against its home index (S&P 500 or ASX 200) and ERP is the equity risk premium — the extra return investors demand for holding stocks over a risk-free asset. Both inputs below are editable assumptions, not live data.

Important caveat: the weights above were chosen purely to minimize risk — the optimizer never looked at expected return at all, CAPM or otherwise. This Sharpe ratio describes the return/risk trade-off that resulted from minimizing risk, not something the optimizer targeted. CAPM's own well-documented weakness is that beta (sensitivity to a single market index) only explains part of real-world stock returns — it's a more principled estimate than a raw trailing average, but still an estimate, not a forecast.

How this is calculated

This solves the classic Markowitz global minimum-variance problem: find portfolio weights w that minimize w¹Σw (portfolio variance), subject to weights summing to 100% and no short-selling (every weight ≥ 0). It does not use expected-return forecasts — this is deliberately the "minimize risk" corner of the efficient frontier, not the "best risk-adjusted return" corner, matching what was asked for.

  • Universe: the full S&P 500 (501 of 503 constituents had usable price history) and ASX 200 (195 of 200) — 696 real, searchable tickers.
  • Σ (the covariance matrix) is built from real daily returns over the trailing ~12 months for whichever tickers you pick, annualized (×252).
  • US and ASX markets trade on different holiday calendars, so returns are aligned by actual shared calendar date (not just "the last N days") before computing covariance — otherwise a mixed US/ASX portfolio would silently compare the wrong days against each other.
  • Solved numerically via projected gradient descent onto the simplex (long-only, fully invested) — there's no closed-form solution once the no-short-selling constraint is added.
  • Your saved ticker list is remembered in this browser only (not shared or sent anywhere) so it's still here if you reload.
  • This is a real optimizer running on real historical data, but a mock-up of the feature — a production version would refresh the price data on a schedule rather than a one-time snapshot.
